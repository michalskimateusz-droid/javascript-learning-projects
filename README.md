# JavaScript Learning Projects

A collection of small JavaScript projects created during my hands-on learning of modern JavaScript fundamentals.

The projects were originally developed while completing a JavaScript course and were later organized into this repository as part of my personal development portfolio.

My main professional background is in Software Quality Assurance and software testing. Learning programming has helped me better understand application logic, improve my technical skills, and develop toward test automation.

## Projects

### 🎯 Guess My Number

A simple browser game where the player tries to guess a randomly generated number.

**Concepts practiced:**

- DOM manipulation
- Event handling
- Conditional logic
- Random number generation
- Application state
- Score and high score management
- Code refactoring
- DRY principle

📁 [`guess-my-number`](./guess-my-number)

---

### 🪟 Modal Window

A simple user interface demonstrating opening and closing modal windows using different types of user interaction.

**Concepts practiced:**

- DOM manipulation
- `querySelector()` and `querySelectorAll()`
- Event listeners
- CSS class manipulation
- Keyboard events
- Event objects
- Functions and basic refactoring

📁 [`modal-window`](./modal-window)

---

### 🐷🎲 Pig Game 

A two-player dice game where players accumulate points while managing the risk of losing their current score.

**Concepts practiced:**

- DOM manipulation
- Event handling
- Random number generation
- Arrays
- Application state
- Dynamic active-player management
- Reusable functions
- Conditional logic
- Game reset functionality

📁 [`pig-game`](./pig-game)
